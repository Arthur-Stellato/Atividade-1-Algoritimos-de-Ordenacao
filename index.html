Quick Sort: visão geral

O que é

Um algoritmo de ordenação por divisão e conquista: escolhe um pivô, particiona o array em torno dele e repete o processo recursivamente.

Para que serve

Organizar dados de forma eficiente — base para buscas rápidas, processamento de grandes volumes e uso geral em software.

Características principais

In-place, recursivo, não estável, e com complexidade média de O(n log n).

Ideia geral de funcionamento

Pivô → particionamento → recursão nas duas metades, até sobrarem apenas pedaços de um elemento.

Contexto de utilização

Uso geral e datasets grandes; versões otimizadas dele aparecem em bibliotecas padrão de várias linguagens de programação.

Como funciona

O Quick Sort segue a estratégia de dividir para conquistar: em vez de comparar todos os elementos entre si, ele separa o problema em pedaços cada vez menores.

Essa mesma divisão se repete, de forma independente, dentro de cada um dos dois grupos — até restarem apenas grupos de 0 ou 1 elemento, que já estão ordenados por definição.

Passo a passo

  1. Escolha do pivô — esta implementação usa sempre o último elemento da faixa.
  2. Particionamento — percorre a faixa comparando cada elemento com o pivô: os menores vão para a esquerda.
  3. Posicionamento do pivô — ao final, o pivô é movido para a posição que já é definitiva no array ordenado.
  4. Recursão — o mesmo processo se repete, separadamente, à esquerda e à direita do pivô.
  5. Caso base — quando a faixa tem 0 ou 1 elemento, a recursão para.
int partition(vector<int>& arr, int low, int high) {
    int pivot = arr[high];
    int i = low - 1;

    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }

    swap(arr[i + 1], arr[high]);
    return i + 1;
}

Vantagens

  • Rápido na prática para grandes volumes de dados
  • In-place — baixo uso de memória extra
  • Fácil de paralelizar (as duas metades são independentes)

Desvantagens

  • Pior caso O(n²)
  • Não é estável
  • Desempenho depende muito da escolha do pivô

Quick Sort vs. Bubble Sort

Os dois são algoritmos de comparação e troca, mas resolvem o problema de formas bem diferentes. O Bubble Sort percorre o array repetidamente, trocando pares adjacentes fora de ordem. O Quick Sort particiona o problema em torno de um pivô e ordena cada metade recursivamente — por isso escala muito melhor conforme o array cresce.

Conclusão

  • O que é: um algoritmo de ordenação por divisão e conquista.
  • Como funciona: escolhe um pivô, particiona o array em torno dele e repete o processo recursivamente.
  • Principais características: rápido na prática, in-place, mas não estável.
  • Vantagens e limitações: ótimo desempenho médio (O(n log n)), mas pior caso O(n²) quando o pivô é mal escolhido.
  • Considerações finais: por isso, implementações usadas de verdade combinam o Quick Sort com outras estratégias — pivô aleatório, mediana de três, ou até outros algoritmos como reforço.
